# Exodus layer (reserved)

This directory will hold class signatures converted from the
[Exodus Privacy](https://reports.exodus-privacy.eu.org/) tracker list, as a
rule-pack layer of its own.

It holds no data yet. The conversion and the differential test against
Exodus reports are task 13 of the milestone-1 build plan.

A converted copy of the Exodus list is a derivative database, so everything
placed here is licensed under the Open Database License 1.0
(`../../LICENSES/ODbL-1.0.txt`) and stays in its own file. It is never merged
into the `core` layer, which is under CC BY 4.0.
