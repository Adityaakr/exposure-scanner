//Sample report

A real report, from the repository's test apps.

This is the HTML report exposure writes, unchanged, from the code this site was built from. It comes from a scan of the synthetic apps the project tests against, so it names no real app. A scan of your own Mac writes the same kind of page, to a folder only you can read.

Open it full page Download the JSON report
  • Skeleton.appA macOS app bundle holding a Sentry framework folder.
  • ElectronSkeleton.appAn Electron app whose archive holds the literals a bundler leaves of the Sentry and PostHog SDKs.
  • Skeleton.apkA 1.8 kB Android package whose code defines PostHog and Sentry classes, plus decoys that must match nothing.
  • Three extensionsTwo Chromium extensions and a Firefox add-on, one asking for every website and one asking for little.

//How it was made

One command, from the repository root.

The site's build compiles exposure from the same commit and runs this command, so the page above is what that code writes. The same fixtures and rule pack give the same bytes on any machine, so you can check it.

$ exposure scan --no-open --no-cache \
    --html report.html --json report.json \
    tests/fixtures/macos/Skeleton.app \
    tests/fixtures/macos/ElectronSkeleton.app \
    tests/fixtures/android/Skeleton.apk \
    tests/fixtures/browser/Extensions \
    tests/fixtures/browser/addon@example.org.xpi
exposure: scanned 3 apps and 3 browser extensions (13 files, 8889 bytes): 14 claims, 0 coverage notes
exposure: headline: 0 companies at contacts or above, 1 company at contains, 2 apps with a third-party channel
exposure: scope: the paths given and nothing else; the installed-app folders were not searched
exposure: beside the headline: 1 SDK of 1 company in the Android apps, in categories the headline does not count

Now scan your own apps.
